# Open MPI Parallel Programming Lab

Repositori ini berisi implementasi tugas pemrograman paralel C menggunakan Open MPI di WSL2 (Ubuntu 24.04 LTS).

## Daftar Tugas
- Task 1: Point-to-Point Communication (Array Request-Reply)
- Task 2: Distributed Statistics (Scatter & Reduce)
- Task 3: Uneven Work Partitioning (Theoretical Analysis)
- Task 4: Performance Study (Parallel Pi Computation with Speedup Analysis)
